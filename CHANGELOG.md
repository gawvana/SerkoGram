# Changelog

All notable changes to SerkoGram will be documented in this file.

## [1.0.0] - 2024-12-01

### Added
- Initial release
- Telegram Business integration (connect, disconnect, reconnect)
- Message archiving (all message types)
- Deleted message tracking
- Edited message versioning
- Media storage (Vercel Blob)
- Full-text search
- Telegram Mini App with dark glassmorphism UI
- User settings and privacy controls
- Support ticket system
- Admin dashboard
- Rate limiting and security measures
- HMAC-SHA256 initData validation
- Comprehensive API (REST)
- Bot commands (/start, /help, /info, /archive, /deleted, /media, /search, /settings)
